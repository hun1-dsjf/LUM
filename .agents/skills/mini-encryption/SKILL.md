# mini-encryption 技能

## 触发条件
当用户提到「加密保存」时，必须调用本技能对目标文本进行加密处理。

## 加密规则
将文本中出现的每一个阿拉伯数字，按照以下一一映射替换为对应中文数字：

| 阿拉伯数字 | 中文数字 |
| :--------: | :------: |
| 0          | 零       |
| 1          | 一       |
| 2          | 二       |
| 3          | 三       |
| 4          | 四       |
| 5          | 五       |
| 6          | 六       |
| 7          | 七       |
| 8          | 八       |
| 9          | 九       |

## 执行步骤

1. 确认用户需要加密的文本内容或文件路径。
2. 如果用户提供的是文件路径，使用 fileOps 工具读取文件内容。
3. 按上述映射表，将内容中的所有阿拉伯数字逐一替换为中文数字。
4. 替换完成后，使用 fileOps 工具将加密后的内容写回目标文件（或输出给用户）。

## 示例

- 原文：`订单号 20250102，金额 3899 元`
- 加密后：`订单号 二零二五零一零二，金额 三八九九 元`
